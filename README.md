# Khamidkhanov Mukhammazokhid: Portfolio

My personal portfolio website. I'm a 16-year-old developer from Namangan, Uzbekistan, with 2 years of experience in backend development, websites, Telegram bots, and apps.

**Live site:** [portfolio-peach-mu-rsjirozwsg.vercel.app](https://portfolio-peach-mu-rsjirozwsg.vercel.app)

## Features

- About, Skills, Projects, and Contact sections
- Responsive layout for phones and desktops
- Skill filters by category
- Scroll and hover animations
- Contact form that delivers messages by email through FormSubmit

## Built with

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run it locally

You need [Node.js](https://nodejs.org) installed.

```bash
git clone https://github.com/khamidkhanov-7/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open the address shown in the terminal, usually `http://localhost:5173`.

## Scripts

| Command             | What it does                     |
| ------------------- | -------------------------------- |
| `npm run dev`       | Starts the development server    |
| `npm run build`     | Builds the site for production   |
| `npm run preview`   | Previews the production build    |
| `npm run lint`      | Checks the code with ESLint      |
| `npm run typecheck` | Checks the TypeScript types      |
